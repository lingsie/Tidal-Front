# 潮汐前线 · Tidal Front v0.6.8.5

[English](README.md) · **简体中文** · [日本語](README.ja.md)

<img src="assets/app-icon-512.png" alt="潮汐前线应用图标" width="128">

一款离线运行的 3D 海岛策略游戏，包含基地经营、资源生产和 NPC 基地攻防。建设防御、训练部队、编组登陆艇，用战舰支援海滩登陆作战。

游戏通过 WebGL2 和 JavaScript 在浏览器中运行，由小型 C++17 服务在本机提供文件。仓库包含源码、图片、音乐和音效；下载完成后，可以离线游玩，无需账号，没有广告和内购。

[下载安装](#安装与启动) · [玩法](#玩法) · [操作](#操作) · [开发验证](#开发验证) · [参与开发](CONTRIBUTING.zh-CN.md) · [音乐署名](CREDITS.zh-CN.md)

## 功能

- **经营海岛基地：**生产金币、木材和钢材，扩充仓库，升级司令部，逐步解锁七种防御。
- **组建登陆部队：**使用步枪兵、重机枪兵、火箭筒兵、坦克和医生。每艘登陆艇只装一种兵，后期最多解锁八艘。
- **战舰支援登陆：**瞄准舰载武器、从海滩部署登陆艇，部队按游戏规则自动推进和作战。
- **探索昼夜海岛：**完整一天为现实 12 分钟；早上、中午、下午、晚上有各自的光照、战斗效果和自适应配乐。
- **查看实际装备：**装备岛提供 Lv.1–10 实际模型和实弹演示；18 种建筑及舰艇拥有 180 张独立等级图。
- **在本机保留进度：**浏览器存档、NPC 防守事件和确定性战斗回放均在本机运行。
- **选择语言：**支持 English、简体中文、日本語。首次启动采用浏览器中受支持的语言，无法匹配时使用英文；手动保存的选择优先。

## v0.6.8.5 更新

- 无人机模型按四段年代演进，从早期简陋装备逐步变为未来设计；后期有四个空心护桨，Lv.10 增加独立细节。
- 无人机启动、起飞、悬停、飞行、返航、降落和停机逐步缓动。一趟只投一枚手雷；目标失效后返航，下次出击重新选人。
- 当前战斗规则为 **30**；规则 29 及以前的战报保留历史无人机行为。
- 180 张独立等级图全部接入建造、查看和升级预览；首次界面语言按浏览器偏好选择。

## 安装与启动

### 运行环境

- Linux 和 Bash。
- 支持 C++17 的 g++。
- 支持 WebGL2 和 Ogg 音频的浏览器。

Node.js 用于开发验证，游玩时不需要它。

Ubuntu / Debian 用户可按需安装编译器和 Git：

```bash
sudo apt-get install g++ git
```

### 克隆并启动

```bash
git clone https://github.com/lingsie/Tidal-Front.git
cd Tidal-Front
./install.sh
```

也可以选择 **Code → Download ZIP**，或[直接下载 main 分支](https://github.com/lingsie/Tidal-Front/archive/refs/heads/main.zip)。解压后进入 `Tidal-Front-main` 目录，运行：

```bash
bash install.sh
```

已有 Linux 发行压缩包的用户，在其 `tidal-front-3d` 目录中执行同一条命令。所有图片和音频均已包含。脚本从源码编译 `tidal-front-server`，并打开：

**http://127.0.0.1:8787/?v=0.6.8.5**

浏览器没有自动打开时，可自行访问该地址。在终端按 **Ctrl+C** 停止游戏服务。默认端口被其他程序占用时，可指定另一个端口：

```bash
TIDAL_PORT=8788 ./install.sh
```

点击游戏中的 ♫ 按钮启用声音；设置面板提供音量和声音兼容选项。

## 存档与更新

存档格式为 **5**，保存在浏览器对游戏地址的 `localStorage` 中。继续使用同一个浏览器、主机名和端口，才能读取原存档；改变其中任何一项都会使用另一份存储。复制项目目录不会复制浏览器存档，清理此站点的浏览器数据会删除对应存档。

Git 安装的用户先用 Ctrl+C 停止服务，然后在项目目录中更新并重启：

```bash
git pull --ff-only
./install.sh
```

ZIP 安装的用户下载、解压新版，并继续使用同一地址启动。受支持的旧档会在加载时迁移；旧单文件 `file://` 版属于另一浏览器来源，无法自动转移存档。

## 玩法

新基地只有司令部。打开建造商店，建造金矿、伐木场、钢厂与防御；把生产点的资源收进仓库，发展基地以满足下一本的升级条件。

建筑施工、建筑与舰艇升级共用 **一个工程位**。兵种与战舰武器升级共用独立的 **训练位**，两个队列可以同时工作。训练提升兵种等级；缺员和换兵都在对应登陆艇中处理。

### 防御解锁

| 司令部等级 | 新解锁防御 |
| ---: | --- |
| 1 | 狙击塔 |
| 2 | 重机枪 |
| 3 | 迫击炮 |
| 4 | 加农炮 |
| 5 | 火箭发射器 |
| 6 | 反坦克导弹架 |
| 7 | 无人机停机坪 |

司令部最高 **10 级**。建筑、兵种和舰艇等级受司令部等级限制；战舰武器还受战舰等级限制。每个基地最多拥有一座无人机停机坪和一座保险库。

侦查 NPC 基地，查看防御和时钟，再发起进攻。登陆艇从海滩逐艇部署，战舰技能消耗能量提供支援。战斗需要在一个完整游戏日内结束；战报保留规则和操作命令，用于确定性回放。

## 操作

| 输入 | 功能 |
| --- | --- |
| 左键点击建筑或停泊舰艇 | 打开信息和操作 |
| 右键拖动 | 旋转视角 |
| 中键拖动或 Shift + 右键拖动 | 平移视角 |
| 滚轮 | 普通场景缩放；装备岛使用固定近景 |
| 移动建筑时左键点击 | 确认可用位置 |
| 移动时右键、X 或 Esc | 取消移动 |
| 数字键 1–8 或船卡 | 战斗中选择可用登陆艇 |
| 选艇后点击海滩 | 部署该艇 |
| 空格 | 暂停 |

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `index.html`、`src/style.css` | 页面结构与布局 |
| `src/main.js` | 界面、输入与游戏流程 |

`.gitignore` 排除编译产物、ZIP、日志和本机缓存。游玩所需图片与音频随源码提交。

## 开发验证

使用 **Node.js 22 或更新版本**。项目没有 npm 包依赖，不需要先执行 `npm install`；`package.json` 声明 ES module，并提供现有检查的一键入口：

```bash
npm test
```

检查覆盖游戏规则、UI / WebGL 调用、发射器、武器、180 张等级图，以及 v0.6.8.4 / v0.6.8.5 回归验证。界面检查使用轻量 DOM / WebGL 替身；涉及的画面、输入和声音还应在实际浏览器中验证。

音频检查需要 **FFmpeg 和 ffprobe**。批量战斗模拟可单独执行：

```bash
npm run test:audio
npm run test:simulate -- 1000
```

开发约定和问题反馈见 [CONTRIBUTING.zh-CN.md](CONTRIBUTING.zh-CN.md)。更详细的中文规则及版本记录保留在[完整玩法指南](docs/zh-CN/GAME_GUIDE.md)中。
