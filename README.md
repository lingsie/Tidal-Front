# 潮汐前线 · Tidal Front v0.6.8.5

一款离线运行的 3D 海岛基地经营与 NPC 攻防游戏。建造基地、训练部队、编组登陆艇，用战舰支援登陆作战；支持中文、English 和日本語，存档保存在自己的浏览器中。

游戏由 WebGL2 / JavaScript 绘制和运行，C++17 服务负责在本机提供页面与资源。无需注册、广告或内购。仓库包含源码以及完整图片、音乐和音效。

## 本版更新

无人机按四段年代演进：1–2 级简陋、3–5 级 50 年代工业、6–8 级 90 年代现代、9–10 级未来；后期带四个空心圆形护桨，10 级有独立机身与停机坪细节。启动、起飞、短暂悬停、降落与停桨逐渐缓动。一趟投一枚手雷，飞行目标死亡后返航，返航装填后再随机选人。规则 30 使用新动作，规则 29 及以前战报保留原轨迹。

七种防御各 1–10 级共 70 张独立透明 PNG，全部由内置 ImageGen 按真实等级模型逐张绘制，使用彩色材质、平视或略仰视。商店显示新建 1 级，建筑详情和侦察显示实际等级，升级预览同时显示当前与下一等级；10 级只显示当前图。司令部、生产建筑、仓库、保险库、战舰和登陆艇的 110 张等级图也已全部接入；现有 18 种建筑及舰艇共 180 张独立缩略图。

首次打开会按浏览器语言偏好选择界面：中文浏览器进入中文、日文浏览器进入日文、英文浏览器进入英文，其他语言默认英文。玩家手动选择过语言后，以保存的选择为准。

无人机停机坪全基地仅限一座，升本不增加名额，NPC 使用同一配额。无人机覆盖基础半径 26，范围内所有存活敌人等概率随机选择，不优先前排、后排、距离或兵种。一趟只投一枚手雷，基础伤害 72、范围半径 2.15，随后飞回停机坪降落，装填 3 秒后才再次起飞。飞行速度 8 米/秒，往返距离越长出击越慢；新规则下飞行中目标死亡或离开有效范围后返航，下次出击重新等概率随机选人；旧规则回放保留原行为。装备岛可直接查看 Lv.1–10 与真实开火演示；10 级新增装甲角柱、发光边框、无人机加固机身与双尾翼，外形区别于中级。商店和建筑详情使用 ImageGen 新生成的透明彩色无人机停机坪缩略图，提示词见 `assets/previews/buildings/drone-imagegen.txt`。新战报使用规则 30，旧战报保留原规则。

0.6.8.3 重做发射器开火动作。Lv.1–2 的反坦克导弹和支架收紧比例，弹体缩小约四成；架上弹与空中弹共用真实模型、颜色和尺寸，从实际轨道连续离架。导弹逐管消耗，整架打空后统一补弹；火箭按各管发射时刻逐个变空，齐射后整组重新装填。装填时弹体沿轨道或筒内滑入，不再留一枚假弹在架上。

Lv.3–5 圆筒使用一次性薄盖，发射前抛盖，装填完成后补新盖；Lv.6–10 方箱使用固定厚度的铰链薄盖板，绕铰链翻开。筒体改为真正中空的几何，盖板移开后能看到内壁、凹入筒口的弹头和发射后的空筒。导弹按真实发射方向加速离架、以低弧线转向目标；尾烟记录已飞过的位置，命中改为短促闪光、少量碎屑和烟尘。战斗伤害、射速和规则版本保持原有数值。


本次修正同步复查全部武器：导弹和火箭 Lv.1–10 的导轨按筒组实际宽度布置，横梁位于筒组下方，侧瞄具和液压杆留出间隙，四级及后续等级不再共用穿筒的旧导轨。火箭弹体进一步缩小，弹头沿低弧线到达每枚火箭的实际散布落点，并在结算落地的同一帧闪爆。命中效果重做为短促核心闪光、带柔边的分散火光、沿抛物线飞散的火花与碎屑，以及延后翻散的烟尘：导弹偏集中闪爆，火箭偏低位向外炸开；烟尘持续约 1.2–1.3 秒后完全消散，不重复结算伤害。舰载火箭和火箭筒兵也使用同一套命中效果。狙击塔、重机枪、迫击炮、加农炮、士兵和舰载武器的动画起点按实际炮口、当前开火管和发射朝向对齐，弹体旋转时仍以弹头位置控制落点。火箭筒兵也改为中空管口与同一枚真实弹体，离管后枪口变空，装填完成再补弹。

保险库在 HQ1–10 均限制为全基地一座，商店、建造校验、升本前置和 NPC 使用同一配额。旧档多余保险库保留等级最高的一座，多余建筑与升级的资源按当前费用退回对应资源点，可按仓库余量收取；减少保险库后超出新仓容的已有库存也移到对应资源点保留。

战舰散射圈也改为累计稳定度：小幅移动只按位移增加少量散布，既有收圈进度保留；大幅换目标时才明显扩散，停止移动后继续收紧。舰炮转动仍锁火，实际炮弹散布使用显示的同一稳定度，回放继续记录每次射击的瞄准质量。

0.6.6 统一等级天花板：建筑、兵种、登陆艇、战舰和五项战舰武器都不得超过当前司令部等级，武器还不得超过战舰等级。旧规则下已升出的超本战舰保留、不回档，但司令部追上前无法继续升战舰，也不会把武器上限抬高。例如 HQ6 / 战舰 Lv.7 / 武器 Lv.5 可将武器升到 Lv.6，然后必须先升 HQ。HQ10 时才允许整套到 Lv.10。Lv.1–5 武器效果保持不变；Lv.6–10 每级只获得前期 **60%** 的效果成长，升级金币和时间则逐级加速上升，防止后期舰炮滚雪球。

原创、离线、无广告、无内购的基地经营和 NPC 攻防游戏。使用 WebGL2 绘制海岛与 3D 建筑，C++17 本地服务提供页面、独立预览图片和原创自适应配乐。战斗、经济、存档都在浏览器本地运行。

## 启动与保存

### 运行环境

需要 Linux、Bash、支持 C++17 的 g++，以及支持 WebGL2 和 Ogg 音频的浏览器。游戏运行时不需要 Node.js；Node.js 只用于开发验证。

Ubuntu / Debian 可先安装编译器和 Git：

```bash
sudo apt-get install g++ git
```

### 从 GitHub 获取并启动

使用 Git：

```bash
git clone https://github.com/lingsie/Tidal-Front.git
cd Tidal-Front
./install.sh
```

也可以在仓库中选择 **Code → Download ZIP**，或[直接下载 main 分支源码](https://github.com/lingsie/Tidal-Front/archive/refs/heads/main.zip)。解压后进入 `Tidal-Front-main` 文件夹，执行：

```bash
bash install.sh
```

已有发行压缩包的用户，解压后在 `tidal-front-3d` 文件夹中执行同一条命令。仓库中的图片和音频下载完成后，可以离线游玩。`install.sh` 会从源码编译 `tidal-front-server`，无需另找预编译程序。

脚本编译本地 C++ 服务，然后打开带版本参数的 `http://127.0.0.1:8787/?v=0.6.8.5`；没有图形桌面时自己在浏览器访问该地址。页面标题和左上角品牌栏会显示当前版本。启动脚本会停止同一用户、同一端口上的旧版潮汐前线进程，避免旧目录继续提供页面；服务会对页面资源发送 `no-store`，确保升级后不再沿用旧血条或旧交互脚本。用 Ctrl+C 停止。端口被其他程序占用时执行 `TIDAL_PORT=8788 ./install.sh`。需要 Linux、g++ 和支持 WebGL2、Ogg 的浏览器，首次点击右上角 ♫ 才播放声音。不要求联网或注册。

### 更新与存档

Git 安装的用户先用 Ctrl+C 停止游戏，然后在项目目录中更新并重新启动：

```bash
git pull --ff-only
./install.sh
```

ZIP 安装的用户下载新版并重新解压、启动即可。继续使用同一个浏览器和 `http://127.0.0.1:8787` 地址，才能读取原存档；更换浏览器、主机名或端口会使用另一份浏览器存储。

存档版本为 5，保存在浏览器对此地址的 `localStorage` 中。更新压缩包后用同一个浏览器和地址打开可以继续原存档；不要清理该站点数据。旧版单文件 `file://` 的存档属于另一个浏览器来源，无法自动转移到本地服务地址。旧存档统一升级过的登陆艇会迁移成逐艇等级。旧版已建的综合仓库继续为三种资源各增加容量；新档只能建对应资源的专用仓库。

## 开局和操作

- 新档只有司令部，先点左下角“建造”。商店同时提供建筑和登陆艇：建筑卡显示独立 PNG、名称、简介、费用、“建造”和“ⓘ 详情”，舰队区显示当前艇数、司令部上限和下一艘价格。**新登陆艇只能从商店购买**；编队页只管理已有登陆艇，并提供前往商店的入口，不再直接扣资源造艇。建筑施工、新登陆艇建造、建筑/登陆艇/战舰升级共用 **1 个工程位**；兵种和战舰武器的训练升级共用 **1 个训练位**。两个位可以并行，但各自一次只跑一项。完工进度在右上角。立即完成采用非线性高价：`ceil(150 + 剩余秒数 × 5 + 剩余秒数² × 0.004)`；10 分钟约 4590 金币，30 分钟 22110 金币，需要谨慎选择。
- 0.5.3 在 0.5.2 的扩岛基础上继续增加纵深：可建区宽度增加约 **13.5%**、纵深增加约 **29%**、总面积再增加约 **47%**，达到最初地图的约 **2.94 倍**。海岛轮廓、装饰、NPC 布局、镜头和平移边界同步扩展，不是只把空白海面拉大。阳光沙滩保留高亮度与明暗对比；海面包含多层动态波纹、波峰、菲涅耳反光、日光高光和近岸浪花。0.6.4 将战场步兵模型缩到原比例的 **62%**、坦克缩到 **70%**，实体碰撞半径也同步收紧，密集编队更容易从建筑缝隙绕行且仍不会互相叠放。
- 0.5.5 在自己基地右侧增加舰队码头：登陆艇分泊在岸线长栈桥，战舰停靠外侧深水泊位，并加入引桥、指泊栈桥、防撞护舷、系缆柱、支撑桩和航灯。码头舰队只在自己的基地出现；侦查与进攻不会展示敌方停泊战舰或登陆艇，战斗仍只显示己方舰炮战舰与已执行冲滩命令的登陆艇。

- 坦克射程保持 **6.4**；加农炮射程为 6.84、狙击塔为 8.16，所以两类前线防御会比坦克更早开始接管。同级加农炮仍恰好三发击毁同级坦克；加农炮高一级时两发击毁低一级坦克；对非坦克单位造成 1.2 倍伤害，通常一炮解决。第 **28** 版不再把平衡倍率藏在部队身上：部队使用面板标出的 **100% 真实伤害**，所有战斗建筑的真实生命值统一提高到原来的 **20/7（约 2.857）倍**，舰炮与火箭齐射的真实伤害也同步提高 **20/7 倍**，所以战舰拆建筑的效果仍保持 0.6.8.2 原平衡。界面、升级对比和装备岛都直接显示这些实际数值。第 27 版战报仍按历史的 35% 部队伤害与旧建筑/战舰数值回放，不会被改写；第 26 版保留 **52%** 的历史部队伤害。四时段各 250 场固定种子混合基准进攻胜率为 **59.8%**；1000 场中不可达为 0、异常种子为 0、回放偏差为 0，5 场在完整战斗日结束时判负。进攻部队仍按最近目标推进，不加入烟幕、土著或绕过沿途建筑直接爆本的机制。单位绕过密集建筑时每帧最多重规划一次，无效短路径会先侧移再于下一帧重试，避免极端布局产生递归栈溢出。当前战斗必须在一个完整游戏日、即 **12 分钟现实时间 / 24 小时游戏时间**内解决；战斗面板从 24:00 倒数。第 24 版及更早战报仍使用各自旧式即时接管和历史防御编制，第 23 版保留旧医生信号弹行为，第 22 版及更早战报仍按历史 130 秒时限回放。战报可按命令以 1×、2×、4× 回放。离线至少 1 小时、距离上次袭击判定至少 8 小时，重新上线时最多进行一次 35% 的 NPC 袭击判定；被打后有 6 小时保护。新档有 24 小时保护。

操作：基地中点建筑或海上登陆艇看详情；战斗中待命艇隐藏，用底部船卡或数字键 1–8 单选/改选一艘。点“移动”后预览、灯光和防御射程跟光标走；左键放下，右键 / ✕ / X / Esc 立即取消。非移动状态下右键拖动旋转视角；按住中键直接拖拽平移（会屏蔽浏览器自动滚屏），Shift+右键也可平移；普通场景滚轮缩放，装备岛固定近距离镜头只允许绕模型旋转；空格暂停。

## 仓库、保险库与 NPC 资源损失

全局仓库中，每种资源初始仓容 **1,800**。金库、木材库、钢库分别只给对应资源提供 **每级 +1,300** 容量；每座保险库自带独立仓储，给金币、木材、钢材分别提供 **每级 +450** 容量，之后再计算保护效果；工地没完工时都不生效。旧档的旧综合仓库继续为三种资源各提供每级 +1,300。资源点另有互不共用的现场容量 `300 × 资源建筑等级`：生产只受本点现场容量限制，收取时再受对应全局仓容限制；搬不进去的部分留在原点。

每种资源不建保险库时也有基础保护，数值为 `max(350, 对应资源仓容的 16%)`，向下取整。全基地只能建一座保险库，每级提供固定保护 `180 + 120 × 等级`，并按该资源**当前库存**再保护 `4% + 3% × 等级`。实际保护量不能超过当前库存。NPC 攻破司令部后，只从扣除保护量的**可掠夺库存**中拿走 14%；建筑没有永久损坏。点保险库可看到基础保护数值、百分比和三种资源当前实际受保护量。

## 司令部解锁与建造配额

HQ 最高 10 级。升级下一本前，本级配额中的所有可建建筑必须全部完工；旧版综合仓库不属于新升本条件。必需建筑、当前已解锁兵种训练和五项战舰武器训练一起计算综合平均等级，门槛为 `ceil(当前 HQ 等级 × 60%)`：例如 HQ6 升 HQ7 要求均级 **4.0+**，HQ9 升 HQ10 要求均级 **6.0+**。单栋建筑可以略低，由其他建筑或训练等级补足，但缺少建筑不能靠高等级抵消。点击司令部会直接列出建筑完成数、当前均级、门槛和缺少项目。

NPC 遵守同一套升本资格：高本基地带齐前一本的资源点、专用仓库、保险库和防御；新本刚解锁的防御至少建一座，因此不会再出现空基地只摆一个火箭发射器。生成时约 14% 抽到“速本”，只有这档贴着前一本和 60% 均级硬下限；68% 正常发育会补齐当前 HQ 新增名额中的大部分并把旧建筑练到接近当前本，18% 重点设防则用满当前建筑配额并把等级推到当前本附近。各项等级仍会在档位附近小幅浮动，所以偶尔会遇到菜岛，但不会再全是速本玩家。防御与资源区改成紧凑、留有模型间隙的互保阵地，不再把塔撒到地图边缘供人逐个拆除。匹配只取自身 HQ 的上下一级，HQ6 只会遇到 HQ5、HQ6、HQ7。七种防御依次在 HQ1 狙击塔、HQ2 重机枪、HQ3 迫击炮、HQ4 加农炮、HQ5 火箭发射器、HQ6 反坦克导弹架、HQ7 无人机停机坪解锁；坦克与医生在 HQ2 解锁。

## 文件结构

- `index.html`：页面元素，不内嵌战斗代码或图片。
- `src/style.css`：界面与移动端布局。
- `src/main.js`：按钮、建造/兵种卡片、输入和游戏流程。
- `src/core.js`：经济、战斗、NPC、离线结算和确定性回放。
- `src/render.js`：海岛、模型、动画与 WebGL2 渲染。
- `src/previews.js`：卡片说明与图片文件路径。
- `assets/previews/buildings/*.{png,jpeg}`、`assets/previews/units/*.png`、`assets/previews/weapons/*.png`：建筑、兵种与战舰武器的独立预览图；反坦克导弹架在界面使用由用户指定成品图去除白底后的透明 PNG，原始 JPEG 完整保留作参考。
- `favicon.ico`、`assets/favicon-*.png`：登陆艇、落日海岛与炮弹轨迹组成的透明正圆浏览器图标；0.5.8 去掉了旧图标的深蓝方底和蓝色外边。
- `assets/app-icon-{192,512,1024}.png`、`manifest.webmanifest`：独立圆角方形手机图标与可安装 Web App 元数据。
- `assets/app-icon-square-master.png`、`assets/app-icon-square-{512,1024}.png`：无圆角、无透明边的纯方手机图标原件；同时作为 Web App 的 maskable 图标源。
- `assets/home_theme.ogg`：基地音乐《Life of Riley》，由 Kevin MacLeod 创作，依据 CC BY 4.0 使用；完整署名见 `CREDITS.md` 与游戏设置页。
- `assets/scout_theme.ogg`：侦查音乐《Stealth Groover》，由 Kevin MacLeod 创作，依据 CC BY 4.0 使用，并在游戏内以较低音量循环播放。
- `assets/battle_{时段}_{stealth,combat}.ogg`：同拍点双轨自适应战斗音乐；未交火与交火状态约 1 秒交叉淡化，停火 6 秒后回到未交火层。早晨采用《Fearless First》/《Sunshine》，中午采用《Funin and Sunin》/《Wepa》，下午采用《Beachfront Celebration》/《Impact Allegretto》，晚上采用《Sunday Dub》/《Got Funk》；四个时段均已按试听结果确认。
- `assets/*.ogg`：配乐与 36 条独立的 48 kHz 立体声拟音；`assets/compose_sfx.py` 可完整重建步枪、狙击枪、机枪、各类火炮、爆炸、按钮、覆盖 15 种建筑的选择反馈（导弹架复用降调火箭架反馈）、战舰、登陆艇和完整冲滩动作音效。
- `server.cpp`、`install.sh`：仅监听本机的 C++ 静态服务及启动脚本。
- `tests/`：规则、UI/WebGL 路径与 100/500/1000 场批量模拟。

## 开发与验证

使用 Node.js 22 或更新版本。项目没有 npm 包依赖，`package.json` 声明 ES module 并提供测试命令，不需要先执行 `npm install`。

```bash
npm test
```

此命令覆盖规则、UI / WebGL 调用、发射器与武器行为、180 张独立等级图片，以及 0.6.8.4 / 0.6.8.5 回归检查。`tests/smoke.mjs` 使用轻量 DOM / WebGL 替身；实际浏览器的画面、输入和声音仍需手动检查。

音频验证需要系统中的 FFmpeg（含 `ffprobe`）；批量模拟可单独运行：

```bash
npm run test:audio
npm run test:simulate -- 1000
```

更多开发约定和问题反馈方法见 [CONTRIBUTING.md](CONTRIBUTING.md)。编译产物、ZIP、日志和本机缓存由 `.gitignore` 排除；游戏所需图片、音乐和音效直接随源码保存。

## 当前状态

目前是可玩的 3D 试玩版；建筑和兵种仍采用本地程序生成的 3D 几何，预览卡使用重新绘制的 PNG。实际战场模型与角色动作尚未达到成熟商业手游水平。基地配乐使用已署名的 CC BY 4.0 曲目，其余现有配乐与音效使用本地程序化乐器/声学分层建模；已有确定性静态障碍绕行，但没有手机安装包、云存档、可破坏地形或多人联网。发行路线确定为保留 WebGL 游戏内核：桌面由原生 C++ 启动器直接启动，手机由系统 WebView 薄壳打成可点图标直开的 APK/IPA，玩家不进入浏览器界面；不采用 Qt。
